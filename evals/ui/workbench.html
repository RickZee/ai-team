Error Analysis Workbench

The human loop from Husain & Shankar, in four stages: read traces and invent codes, cluster them, derive the taxonomy, then earn a judge. Each stage unlocks only when the previous one has done enough work to justify it.

Runs entirely in this page. No network, no model calls, nothing leaves your machine. Stage 1 shows you no suggestions of any kind — that is the point of it (eval-harness R3.7).

Drop a trace bundle here
or click to choose — bundle.json
  1. Sample a batch to read:
    uv run python -m evals.cli sample --strategy stratified -n 100 --seed 1
  2. Bundle it for this page:
    uv run python -m evals.cli annotate bundle --sample <sample_id> --out bundle.json
  3. Read and code the traces here, then Export.
  4. Ingest what you wrote:
    uv run python -m evals.cli annotate --sample <sample_id> --batch-file annotations.jsonl

Axial coding

Your codes, normalised and counted the same way evals/taxonomy/propose.py does it — lowercase, snake_case, punctuation stripped. Clustering is arithmetic, not a model. Accept a cluster to carry it into stage 3, merge near-duplicates, reject noise. The working target is 5–8 categories on a first pass.
