## 5. The backfill label fix (same session)

`TraceBuilder.from_workspace` now reads the run record: backend from `run.json` (top level or
`extra`), status from `extra.final_status` or a `complete` phase in `state.json`, and start/end
from `run.json` when a trace has no spans (so a backfill no longer stamps every trace with build
time — the "1.97-second window" in the 2026-09-13 audit). Unrecorded backends become
**`unknown`** (new `BackendName` value) with a warning; unrecorded statuses still default to
`failed`, now with a warning. `trace backfill` passes `backend=None` and gained `--backend` to
force one. Writer side: `ResultsBundle.finalize(backend=...)` fills a missing backend, and the
web server passes it — the web path was why 113 runs had none.

After, on 338 runs: `langgraph 223 · unknown 113 · crewai 1 · claude-agent-sdk 1`;
`complete 209 · failed 129`; 240 with zero spans. 4 builder tests + 1 bundle test added;
`from_workspace` split into `_resolve_clock` / `_resolve_status` to stay under the
150-line function ratchet. Unit suite: 1,614 passed; the one failure was the link guard
seeing untracked files, cleared by the commit.

**Still open:** `failed` conflates "failed" with "never recorded a status". A proper fix
is an `unknown` status, which touches sampling strata and several checks — not done.

## 6. Automated course testing

`/test-course` in Cursor runs the `course-test` skill. Parameters: `scope` (all / week / step),
`mode` (**stranger** = fresh clone, no history, no keys — default; maintainer = this
checkout), `budget_usd` (**$10** default from the command), `fix` (docs-only P0/P1 fixes on a
branch, never pushed). Per step it predicts as a newcomer, runs the commands verbatim, grades
the output against the page (`MATCH` / `DRIFT` / `MISMATCH` / `BROKEN` / `SKIPPED-*`), scores
each week on six dimensions (runs, accurate, clear, teaches, honest, fits budget), and writes
`course/testing/runs/<date>-<mode>/` — `report.md`, `observations.jsonl`, `spend.jsonl`,
`logs/` (gitignored). It never does week 4's reading (≤2 `SIMULATED` notes, never in
`evals/annotations/`) and never changes system code.

**Spend plan for $10** (skill §2a): W1 real run (~$0.05) → W2 three backends (~$1.10) → W6
`--n 5` batch (~$4.50) → W6 `smoke-claude` batch at `--n 1` (~$3, recorded as
`DEVIATION-BUDGET`; `--n 5` would be ~$12). $0.50 reserve; actual cost per run logged; a
missing cost counts at its projection and is a finding. Week 6 batches run as a baseline —
the agent doesn't make the fix. Costs are from history: DeepSeek-tier runs cost pennies,
Claude SDK runs $0.48–$0.95, so a Claude run may hit the labs' $1 cap — that would be a P1
against the labs.

**Pilot** (`course/testing/runs/2026-09-16-pilot/`, stranger mode, $0, W1.S2 + W3 + W4.S1):

## 8. The LangGraph guardrail loop, fixed

The 2026-09-13 smoke run (1,600 s → HITL) had four causes, all confirmed in code and fixed:

| # | Defect | Fix |
| --- | --- | --- |
| 1 | Guardrails scored the last 12 messages of the **seeded run history**, so QA was judged on the architect's ADR | `current_turn()`: score only messages after the phase's own `HumanMessage` (retries keep earlier attempts of the same phase) — behavioral, security and quality nodes |
| 2 | Single-agent planning/development filtered on a supervisor name that didn't exist → behavioral guardrail passed **vacuously** | `behavioral_only_message_names=None` in single-agent mode |
| 3 | Testing-phase `GuardrailError` → `retry_development` | → `human_review`; tool-call crashes still retry |
| 4 | Testing prompt and `_snapshot_workspace_files` used the parent `./workspace` | `get_workspace_dir()` (run-scoped) — the "Path must be under workspace" crash, nested folders and the 260-file inventory |

`tests/unit/backends/langgraph_backend/test_guardrail_loop_regression.py` rebuilds the 09-13
situation: old scoring fails correct QA test code at **8%** (floor 15%); 7 of 9 tests fail on
the old code. Unit suite 1,628 passed.

**Behaviour change to watch:** defect 2's fix means single-agent planning (architect) and
development (fullstack) are now actually checked for scope. That could surface new false
positives on live runs; none observed yet because —
