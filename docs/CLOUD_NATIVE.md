# Cloud-native backends

Status of each backend on each execution target. A cell is `green` only after a
recorded run. `not yet` means the target is planned and not demonstrated.
`not available` means that backend will not run there. No cell is left blank.

The date, run id, model, and cost on a `not yet` or `not available` row are
`—` until a run exists. Local runs that do exist stay labeled `model_tier: local`
and cost `$0` so they are not read as a quality result.
